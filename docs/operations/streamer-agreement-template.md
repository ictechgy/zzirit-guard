# 운영 합의서(초안)

> 법률 검토 전 초안이다. 누가 개인정보처리자이고 누가 수탁자인지는 법률 검토를 받아 확정한다(스펙 9장).

- **당사자**: 스트리머 [채널명] / 운영자 [이름]
- **목적**: [채널명] 방송 채팅의 악플·도배 대응 보조(찌리릿 가드 운영)
- **처리하는 정보**: 방송 채팅(닉네임·채널 ID·내용·시각). 문제로 판정되지 않은 채팅은 저장하지 않는다. 조치 기록에는 원문 없이 대상의 채널 ID와 조치 내용·시각을 남긴다.
- **처리 장소**: 운영자의 맥 미니(FileVault 암호화). 판정과 저장은 운영자 컴퓨터에서만 하고, 매니저 휴대폰에는 암호화된 연결로 보여 줄 뿐 따로 저장하지 않습니다. 외부 AI나 다른 회사로 보내지 않습니다. 외부 접속은 Tailscale Funnel로 하며, Tailscale 문서에 따르면 중계 서버는 암호화된 트래픽만 전달한다. 푸시 알림에는 장애 상태 알림만 담긴다.
- **보관 기간**: 판정된 채팅 원문 [30]일, 원문 없는 조치 기록 [180]일. 기간이 지나면 매일 자동 삭제한다. 매일 백업을 7개까지 두므로 지운 원문도 **백업에 최대 7일 더 남는다**.
- **요주의 사용자**: 최근 180일(조치 기록 보관 기간이 더 짧으면 그 기간)의 조치 기록에 숨김·임시 제한·활동 제한이 있는 사용자의 채팅은 매니저 확인 후보로 올린다(자동 숨김 아님). 별도 명단은 저장하지 않고 조치 기록에서 계산한다. 이 기간에는 그 사용자의 채팅(가벼운 반응·허용어 제외)이 모두 후보로 저장되어 원문이 판정 원문 보관 기간 동안 남는다.
- **토큰**: 스트리머 치지직 토큰은 암호화해 보관하고, 숨김·제재·채팅 설정 외의 용도로 쓰지 않는다.
- **제재 원칙**: 자동 숨김은 스트리머·채널 관리자가 켠 동안만, 제재는 사람만. 활동 제한(영구)과 그 해제는 이 앱에 화면이 없어 치지직 기본 도구로 한다.
- **유료화 없음**: 치지직 약관 제7조②13호에 따라 대가를 받지 않는다.
- **종료**: 어느 쪽이든 알리면 종료한다. 종료 시 운영자는 채널 연결을 해제하고 DB·백업과 서버 로그(매니저 채널 ID가 들어 있다)를 [7]일 안에 지운다.
- **연락처**: 스트리머 [ ] / 운영자 [ ]
