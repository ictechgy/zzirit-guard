# 찌리릿 가드(zzirit-guard) 설계

- 작성일: 2026-10-11
- 상태: 사용자 검토 대기
- 근거 자료: [스파이크: 로컬 가드 모델 비교](../../spikes/2026-10-11-guard-models/README.md)

## 1. 목표

치지직 스트리머와 채팅 매니저를 위한 **채팅 관리 보조 도구**다. 악플과 도배에 늦게 대응하는 문제를 줄인다.

**사용자가 정한 것**
- 첫 목표는 아는 채널에서 실제로 쓰는 것이다. 결제와 가입은 뒤로 미룬다.
- 확실한 것만 자동으로 숨기고, 애매한 것은 매니저에게 올린다. 제재(임시 제한·영구 제한)는 사람만 한다.
- 자동 숨김은 **켜고 끌 수 있어야** 한다. 기본값은 꺼짐이다.
- 매니저의 기기를 모르므로 모바일 우선 웹앱(PWA)으로 만든다.
- 설계 목표는 피크에 초당 수십 건 이상 들어오는 채팅을 처리하는 것이다.
- 외부 접속은 우선 Tailscale Funnel로 하고, 나중에 Cloudflare로 바꿀 수 있어야 한다.

**가정(검토 때 정정 가능)**
- MVP는 **채널 1곳**을 운영한다. 데이터 모델에는 `channel_id`를 둬서 확장할 수 있게 한다. 근거는 두 가지다. 채팅이 많은 채널 하나가 맥 미니의 AI 처리 용량을 대부분 쓴다. 그리고 다채널 운영 화면은 아직 필요가 확인되지 않았다.
- 서버와 AI는 사용자의 맥 미니(M4 Pro, 24GB) 한 대에서 돈다.

## 2. 범위

**이 스펙이 다루는 범위는 로드맵 1~3단계다(15장).**
- **MVP(1단계)**: 치지직 연결, 채팅 수신, 규칙 감지, 섀도 모드, 자동 숨김 스위치, 매니저 PWA(후보 처리·수동 조치·설정·기록), 감사 기록, 건수 통계.
- **2단계**: AI 감지(1차·2차 워커).
- **3단계**: 규칙 기반 자동 숨김 켜기.

구현 계획은 단계별로 따로 쓴다. 1단계 계획을 먼저 쓴다.

**제외(YAGNI)**
- 결제·가입·광고. 치지직 개발자 약관 제7조②13호가 금지한다. 유료화는 치지직과 제휴해야 한다.
- 외부 AI API. 국외 이전과 약관 제7조②11호 문제가 있다.
- 숨김 해제. 치지직 API가 없다.
- 실채팅으로 하는 모델 재학습. 치지직의 서면 회신 전에는 하지 않는다.
- 네이티브 앱, 다채널 동시 운영 화면, Cloudflare 전환. 전환은 가능하게만 설계한다.

## 3. 외부 제약

| 출처 | 제약 | 설계에 준 영향 |
|---|---|---|
| 치지직 Open API | 쓰기 API(숨김·제한·채팅 설정)는 **스트리머 토큰으로만** 된다. 다른 계정으로 부르면 400 "스트리머가 아닙니다"가 온다 | 스트리머가 한 번 연결하면 서버가 토큰을 보관하고, 매니저 조치는 서버가 대신 실행한다 |
| 치지직 Open API | Access Token은 1일, Refresh Token은 30일이고 **한 번만 쓸 수 있다** | 갱신은 한 곳에서만 하고, 새 토큰을 저장한 다음에 사용한다 |
| 치지직 Session API | Socket.IO(socket.io-client 1.0.0~2.0.3만 지원). 유저 인증 세션은 3개까지 | 서버(Node)에서 `socket.io-client@2.0.3`을 쓴다 |
| 치지직 Open API | 숨김 해제 API가 없다. 호출 한도는 "초과 시 429"라고만 되어 있다 | 자동 숨김 기본값을 꺼짐으로 하고 섀도 모드를 둔다. 실행기에 대기열과 재시도를 둔다 |
| 치지직 Open API | `GET /open/v1/channels/streaming-roles`는 요청한 채널의 관리자 목록을 준다(managerChannelId, userRole) | 매니저 로그인 검증에 쓴다 |
| 치지직 개발자 약관 | 제7조②11호(제3자 공유 금지), 13호(유료화·광고 금지), 제8조(데이터 권리는 회사에 있음). 앱 이름에 chzzk·치지직·naver·네이버를 쓸 수 없다. 90일 동안 사용 이력이 없으면 앱이 삭제된다 | 로컬 처리만 한다. 무료로 운영한다. 재학습은 회신 뒤에 한다. 이름은 찌리릿 가드로 정했다 |
| 치지직 개발자 약관 | 제7조④ "회사가 지정하는 방식에 따라 치지직 API 서비스를 이용한 것임을 표시", ③ 클라이언트 아이디는 본인만 사용, 14호(치지직으로 오인될 앱 금지), 15호(브랜드 훼손 금지) | PWA에 치지직 API 사용 표시를 넣는다(방식은 0단계에서 확인). 치지직 로고·디자인을 흉내 내지 않는다 |
| 개인정보보호법 | 제28조의8(국외 이전), 제26조(위탁), 제37조의2(자동화된 결정: ④항이 기준·절차 공개를 요구한다) | 채팅을 외부로 보내지 않는다. 자동 숨김 기준을 공개하고 이의 제기 경로를 둔다 |

## 4. 전체 구조

```
치지직 ──채팅 이벤트(Socket.IO)──▶ [채팅 수신] ──▶ [판정 파이프라인] ──자동 숨김──▶ [실행기] ──쓰기 API──▶ 치지직
                                                   │        ▲                  ▲
                                         HTTP(127.0.0.1)    │                  │
                                         [1차 분류기 워커]   │       매니저 조치(숨김·제한·저속 모드)
                                         [2차 분류기 워커]   │                  │
                                                   └─후보─▶ [매니저 연결] ◀──WebSocket·REST──▶ 매니저 PWA
                                     모든 판정·조치 ──▶ [기록] (SQLite)
```

**프로세스**(맥 미니, launchd가 각각 KeepAlive로 관리한다)

| 프로세스 | 언어·런타임 | 역할 |
|---|---|---|
| `server` | Node.js 22 + TypeScript | 연결 관리, 채팅 수신, 판정 파이프라인(규칙·건너뛰기·대기열), 실행기, 매니저 연결(REST·WebSocket), 기록, PWA 정적 파일 제공 |
| `stage1-worker` | Python 3.12 + PyTorch(CPU) | KcELECTRA 1차 점수. GPU를 쓰지 않아 2차와 다투지 않는다 |
| `stage2-worker` | Python 3.12 + mlx-lm(GPU) | kanana-safeguard-8b 4비트 판정. 접두 KV 캐시를 쓴다 |

**서버 구성 요소**

| 구성 요소 | 하는 일 | 의존하는 것 |
|---|---|---|
| 연결 관리 | 스트리머 OAuth 연결, 토큰 암호화 보관, 선제 갱신(만료 2시간 전), 갱신 실패 시 쓰기 중지 | 치지직 OAuth, 키체인, DB |
| 채팅 수신 | Session API 연결 1개 유지, CHAT 이벤트 구독, 끊기면 지수 백오프로 재연결 | 연결 관리 |
| 판정 파이프라인 | 5장의 단계를 거쳐 메시지마다 판정과 이유를 붙인다 | 규칙 저장소, 분류기 인터페이스 |
| 실행기 | **모든 쓰기 API가 지나는 유일한 통로**. 대기열, 429 재시도, 폭주 차단, 감사 기록 | 연결 관리, 기록 |
| 매니저 연결 | 매니저 로그인, 역할 확인, 실시간 전송, 조치 요청 접수 | 치지직 OAuth, streaming-roles, 실행기 |
| 기록 | 판정·조치·설정 변경 저장, 보관 기한 삭제, 분당 통계 | DB |

**저장소 구조(npm workspaces + uv)**

```
apps/server/        Node 서버
apps/web/           PWA (React + Vite + TypeScript)
packages/shared/    서버·웹 공용 타입(REST·WebSocket 메시지)
workers/stage1/     KcELECTRA 워커 (Python, uv)
workers/stage2/     kanana 워커 (Python, uv)
docs/
```

PWA를 React로 하는 이유는, 채팅 텍스트를 기본으로 이스케이프해서 XSS 실수를 줄이기 때문이다.

## 5. 판정 파이프라인

메시지마다 다음 순서로 처리하고, 앞 단계에서 결정되면 멈춘다.

```
수신 ─▶ ① 보낸 사람 확인 ─▶ ② 규칙 ─▶ ③ 건너뛰기·중복 ─▶ ④ 1차 분류기 ─▶ ⑤ 2차 분류기(kanana) ─▶ 판정
```

### 5.1 판정 종류

| 판정 | 의미 | 처리 |
|---|---|---|
| `auto_hide` | 확실히 숨길 것 | 스위치가 **켜져 있으면** 실행기로 숨긴다. 꺼져 있으면 `shadow`로 기록하고, 후보 목록 맨 위에 "켜져 있었으면 숨겼을 메시지"로 표시한다 |
| `candidate` | 매니저 확인이 필요함 | 후보 목록에 올린다. AI가 확률 0.99 이상으로 판정한 것은 '확실' 배지를 붙인다 |
| `needs_care` | 자해·자살 신호 | 숨김 후보가 아니라 **별도 "도움 필요" 표시**로 올린다 |
| `pass` | 문제없음 | 저장하지 않는다(통계 건수만 센다) |

### 5.2 단계별 규칙

**① 보낸 사람 확인**: 스트리머나 매니저(`userRoleCode`)의 메시지는 절대 `auto_hide`가 되지 않는다. 걸려도 최대 `candidate`다. `userRoleCode`가 없거나 문서에 없는 값이면 권한자인지 알 수 없으므로 같은 방식으로 `candidate`로 낮춘다(이유 꼬리표 `:unknown_role`).

**② 규칙**(즉시 처리, 예측할 수 있어야 함)

비교하기 전에 문장을 정규화한다. 공백과 특수문자를 지우고, 반복 글자를 줄이고, 비슷한 숫자·기호를 치환하고(예: `1`→`ㅣ`, `0`→`ㅇ`), 흩어진 자모를 조합한다(예: `시 ㅂ ㅏ`→`시바`).

| 규칙 | 조건(기본값, 채널별로 바꿀 수 있음) | 판정 |
|---|---|---|
| 금칙어 강 | 채널 목록과 일치 | `auto_hide` |
| 떼도배 | 정규화한 길이 **10자 이상**인 같은 문장이 10초 안에 서로 다른 사용자 5명 이상 | `auto_hide` |
| 광고 링크 | URL, 오픈채팅(open.kakao.com), 텔레그램(t.me·"텔레"+아이디), 도박 키워드+연락처. 채널 허용 도메인은 제외. 아래 '한글 주소'는 도박 키워드와 함께일 때만 여기에 든다 | `auto_hide` |
| 허용 주소에 붙은 한글 | 허용 도메인 바로 앞에 한글을 띄어 쓰지 않고 붙여(예: 카지노youtube.com) 다른 주소(한글 IDN)로 읽힐 수 있는 링크 | `candidate`(`rule:link_glued`) |
| 한글 주소 | 등록 도메인 이름(최상위 도메인 바로 앞 라벨)이 한글이고, `http(s)://`·`www.`·경로(`/`)·포트·퓨니코드(`xn--`) 단서가 하나도 없는 주소(예: 좋아요.me, 구글.com에서, 가자.한국) | `candidate`(`rule:link_idn`) |
| 전화번호 | 휴대전화 번호 패턴(010·011 등 + 7~8자리) | `auto_hide` |
| 금칙어 약 | 채널 목록과 일치 | `candidate` |
| 예외 단어 | 금칙어를 품은 정상 단어(예: 시발점). 금칙어 강·약·협박을 비교하기 전에 지운다 | (판정 없음) |
| 개인 도배 | 한 사람이 10초 안에 5건 이상 | `candidate` |
| 협박 표현 | 협박 표현 목록(예: 찾아간다, 집 앞, 칼 들고, 알아냈다) | `candidate` |
| 주소·실명 | 주소 패턴(○○동·아파트·호수) | `candidate` |
| 요주의 사용자 | 최근 180일 감사 기록에 조치 이력이 있음 | `candidate`(AI 단계에서도 우선순위를 올림) |
| 채널 허용어 | 정규화한 메시지 **전체**가 채널이 등록한 표현과 같을 때만(예: "적팀죽여버려"). 부분 일치로 통과시키면 "스트리머 죽여버려"까지 통과하기 때문이다 | 금칙어 약·협박 표현·AI 판정보다 우선해서 `pass`(금칙어 강·광고·전화번호보다는 후순위) |

한글 주소를 자동 숨김하지 않는 이유(판단 U2): "좋아요.me", "가자.한국!"처럼 한글 낱말 뒤에 마침표와 흔한 영문 낱말이 오는 정상 채팅과 모양이 같다. 그래서 "무료쿠폰.kr" 같은 실제 스팸 주소도 단서가 없으면 후보에 머문다. 자동 숨김은 되돌릴 수 없어 확실할 때만 쓰고, 이런 주소는 매니저가 후보로 보고 처리한다. 도박 키워드가 함께 있으면 연락 수단으로 보고 자동 숨김을 유지한다. 한글 라벨이 영문 도메인의 하위 주소일 뿐이면(예: 좋아.evil.com, 등록 도메인 evil.com) 한글 주소로 보지 않고 광고 링크로 숨긴다. 같은 메시지의 다른 영문 링크도 그대로 광고 링크로 숨긴다.

떼도배가 감지되면 10초 창 안의 같은 문장을 **앞선 것까지 모두** 숨긴다. 창 안의 메시지 식별값은 메모리 버퍼에 보관한다.

떼도배에 최소 길이를 둔 이유가 있다. 대형 채널에서는 "ㅋㅋㅋㅋ", "GG" 같은 집단 반응이 정상이라, 이를 도배로 숨기면 사고가 난다.

**③ 건너뛰기·중복**
- 정규화한 문장이 ㅋ·ㅎ·ㄷ·ㅠ·ㅜ·문장부호·이모티콘으로만 되어 있으면 AI 단계를 건너뛰고 `pass`한다.
- 같은 정규화 문장의 AI 판정은 10분 동안 재사용한다(최대 1만 건 LRU).

**④ 1차 분류기**(KcELECTRA, CPU, 최대 16건씩 묶음)
- 점수가 **0.05 이상**이거나 **키워드 경로**에 걸리면 2차로 보낸다. 그 밖에는 `pass`다.
- 키워드 경로는 1차 분류기가 못 잡는 범주(성희롱·자해·미성년 대상)의 단어를 넓게 모은 목록이다. 넓게 잡아도 최종 판정은 2차가 한다.

**⑤ 2차 분류기**(kanana-safeguard-8b 4비트, GPU, 직렬, 접두 KV 캐시)
- 유해 확률(UNSAFE 토큰 확률 합)이 0.5 이상이면 `candidate`, 0.99 이상이면 '확실' 배지를 붙인다.
- 유해 확률이 0.5 이상이고 가장 높은 범주가 S6(자살·자해)이면 `needs_care`다.
- AI 판정은 **절대 `auto_hide`가 되지 않는다.** 경계 판정이 설정에 따라 뒤집히는 것을 스파이크에서 확인했다. AI 자동 숨김은 섀도 데이터를 보고 나중에 다시 결정한다.
- kanana는 문맥을 지원하지 않으므로 메시지 하나만 넘긴다. 같은 사람의 이전 메시지는 매니저 화면에서 사용자 단위로 묶어 보여 준다(6장).

### 5.3 분류기 인터페이스(바꿔 끼울 수 있게)

서버는 두 워커를 같은 형태로 부른다. 모델을 바꿔도 서버는 그대로 둔다.

```
POST http://127.0.0.1:8711/classify   (1차 워커. 2차 워커는 8712)
요청: { "items": [ { "id": "msg-123", "text": "..." } ] }
응답: { "model": "kanana-safeguard-8b@mlx-4bit", "items": [ { "id": "msg-123", "unsafe_probability": 0.97, "category": "S2" } ] }
```

- 1차 워커는 `category`를 `null`로 준다.
- 요청에는 실행할 때 만든 비밀값 헤더를 붙인다. 같은 맥의 다른 프로세스가 마음대로 부르지 못하게 하기 위해서다.
- 채팅은 모델 프롬프트에 **데이터로만** 넣는다. 지시문 공격 2건을 kanana가 정상 판정한 것을 스파이크에서 확인했다. 조작에 성공해도 결과는 후보 추가에 그친다.

### 5.4 과부하 정책

- 2차 대기열은 최대 300건이다. 15초가 지난 항목은 버린다. 그때쯤이면 채팅이 이미 지나갔기 때문이다.
- 우선순위는 키워드 경로, 요주의 사용자, 첫 채팅 사용자(서버가 이번 방송에 연결한 뒤 처음 본 사용자), 1차 점수 순이다.
- 버린 건수는 분당 통계("AI 미검사")로 세고, 매니저 화면에 표시한다.

### 5.5 자동 숨김 스위치와 안전장치

- 스위치 상태는 모든 매니저 화면에 즉시 반영되고, 누가 언제 바꿨는지 기록에 남는다.
- **폭주 차단**: 자동 숨김이 1분에 60건을 넘으면 스위치를 자동으로 끄고 알린다. 기본값이고 섀도 데이터를 보고 조정한다. 예를 들어 실수로 "ㅋ"를 금칙어에 넣은 사고를 막는다.
- **오판 신고**: 자동 숨김마다 이유(규칙 번호)를 표시한다. 매니저가 "오판"을 누르면 그 규칙이 검토 목록에 올라간다.

## 6. 매니저 PWA

**화면 3개**
1. **후보**: 맨 위에 스위치와 상태 배너(치지직 연결, AI 상태, 미검사 건수)를 둔다.
   - 후보는 **사용자 단위로 묶는다.** 최근 10분 동안의 건수, 최고 확률, 최근 메시지 3개를 보여 준다.
   - 버튼: 메시지별 숨김, 사용자 임시 제한, 무시.
   - "켜져 있었으면 숨겼을" 항목과 "도움 필요" 항목은 따로 구분해 표시한다.
2. **실시간 채팅**: 위험 메시지를 강조하고, 위험한 것만 보는 필터를 둔다.
3. **기록·설정**: 감사 기록, 금칙어·허용어·허용 도메인, 임계값, 보관 기간, 상태 점검(연결, 토큰 만료, 워커, 대기열, 마지막 이벤트 시각).

**아이콘**: PWA 아이콘과 파비콘은 `assets/logo/zzirit-guard-mark.svg`에서 만든다.

**치지직 API 사용 표시**: 약관 제7조④에 따라 치지직이 지정한 방식으로 로그인 화면과 설정 화면에 표시한다.

**알림**: Web Push(VAPID)로 재연결 필요, 자동 숨김 자동 꺼짐, 서버·AI 장애를 알린다. iOS는 홈 화면에 추가한 PWA에서만 받는다(iOS 16.4 이상).

## 7. 권한

**채널 연결**: 연결은 운영자가 설정한 스트리머 채널(`ZG_CHANNEL_ID`)만 허용한다. 공개 주소라서, 설정하지 않으면 스트리머보다 먼저 아무나 자기 채널을 연결해 서버를 가로챌 수 있기 때문이다.

**매니저 로그인 절차**
1. 매니저가 자기 치지직 계정으로 OAuth 로그인한다.
2. 서버가 `GET /open/v1/users/me`로 `channelId`를 확인한다.
3. 스트리머 토큰으로 받은 관리자 목록(`streaming-roles`, 5분 캐시)에 그 `channelId`가 있는지 확인한다.
4. 통과하면 세션을 발급한다. **매니저 토큰은 확인 직후 버리고 저장하지 않는다.** 치지직 토큰 폐기(revoke) API도 부르지 않는다. 폐기하면 같은 앱·같은 사용자의 토큰이 모두 지워져, 스트리머 본인이 로그인한 경우 보관 중인 스트리머 토큰까지 사라진다.
5. 역할은 WebSocket을 연결할 때와 5분마다 다시 확인한다. 목록에서 빠지면 세션을 끊는다.

| 기능 | 스트리머 | 채널 관리자 | 채팅 운영자 |
|---|---|---|---|
| 치지직 연결·해제 | ✅ | ❌ | ❌ |
| 자동 숨김 **끄기** | ✅ | ✅ | ✅ |
| 자동 숨김 **켜기**, 규칙·허용어·임계값 수정 | ✅ | ✅ | ❌ |
| 수동 숨김, 임시 제한 | ✅ | ✅ | ✅ |
| 영구 제한·해제, 채팅 설정(저속 모드 등), 감사 기록 열람 | ✅ | ✅ | ❌ |

정산 관리자는 접근할 수 없다. 끄기 권한을 더 넓게 준 이유는 끄기가 안전한 방향이기 때문이다.

## 8. 보안

- **토큰**: AES-256-GCM으로 암호화해 DB에 저장한다. 키는 macOS 키체인에 두고 `security` 명령으로 읽는다. 토큰은 서버 밖으로 나가지 않는다.
- **갱신**: 한 번에 하나만 실행한다. 새 토큰을 트랜잭션으로 저장한 뒤에 사용한다.
- **세션**: HttpOnly·Secure·SameSite=Lax 쿠키를 쓰고 12시간 뒤 만료한다. WebSocket은 REST로 받은 30초짜리 일회용 티켓으로 인증하고, Origin을 검사한다.
- **채팅은 공격자가 쓴 입력이다**: 화면에는 텍스트로만 렌더링한다(`dangerouslySetInnerHTML` 금지, CSP 적용). 앱 로그에는 채팅 원문을 남기지 않고 식별자만 남긴다.
- **네트워크**: 서버(8710)와 워커(8711·8712)는 127.0.0.1에만 바인딩한다. 외부에서는 Funnel → 8710으로만 들어온다(12장).
- **구버전 Socket.IO**: 치지직이 socket.io-client 2.0.3까지만 지원해서 알려진 취약점이 있는 구버전 의존성을 쓸 수밖에 없다. 채팅 수신 모듈 안에서만 쓰고, 연결 대상은 치지직이 발급한 세션 URL로만 제한하며, `npm audit` 결과를 기록해 둔다.
- **호스트**: FileVault를 켜고 잠자기를 끈다(`pmset`). 의존성 버전은 고정한다.

## 9. 개인정보와 데이터

- **최소 저장**: `candidate`·`shadow`·`needs_care`·`auto_hide`이거나 조치된 메시지만 저장한다. 그 밖의 채팅은 메모리에서 판정한 뒤 버리고, 통계는 건수만 센다.
- **보관 기간**(기본값, 설정에서 변경 가능): 원문이 들어간 판정 기록은 30일, 원문을 뺀 감사 기록은 180일이다. 매일 기한이 지난 기록을 삭제한다.
- **기준 공개**(제37조의2 ④): 채널 공지에 자동 숨김 기준과 이의 제기 경로를 올린다. 숨긴 메시지는 되돌릴 수 없다. 그래서 이의 제기의 결과는 기록 정정과 제재 해제까지로 한정한다고 함께 적는다.
- **외부 전송 없음**: 모든 판정을 맥 미니 안에서 한다. Funnel 중계 서버는 암호화된 트래픽과 호스트 이름만 본다.
- **학습 데이터**: 치지직의 서면 회신 전에는 실채팅을 학습·평가용으로 따로 모으지 않는다. 회신 뒤에 모은다면 운영 기록과 분리하고 `{문장, 라벨}`만 남긴다. 식별자와 시각은 지우고, 개인정보는 가린다.
- **운영 합의**: 스트리머와 운영자 사이에 서면 합의를 한다. 처리하는 데이터, 목적, 보관 기간, 종료 시 삭제를 적는다. 누가 처리자이고 누가 수탁자인지는 법률 검토를 받는다.

## 10. 장애 대응

원칙: **장애가 나면 자동 조치를 멈추고 사람에게 넘긴다.** 이 앱이 없어도 매니저는 치지직 기본 도구로 관리할 수 있다.

| 장애 | 대응 |
|---|---|
| 치지직 연결 끊김 | 지수 백오프(최대 30초 간격)로 재연결한다. 끊긴 동안의 채팅은 놓친다. 배너를 띄우고 통계에 기록한다 |
| 토큰 갱신 실패 | 쓰기를 중지(조회만 가능)하고 스트리머에게 "재연결 필요" 푸시를 보낸다 |
| 쓰기 API 429·5xx | 실행기가 백오프하며 최대 3회 재시도한다. 1분 동안 실패율이 50%를 넘으면 자동 숨김을 끄고 알린다 |
| 쓰기 API 응답 시간 초과·연결 끊김 | 치지직이 이미 처리했을 수 있어 다시 보내지 않는다. "결과를 알 수 없으니 확인한 뒤 다시 시도"로 알린다. 연결 거부·DNS 실패(요청이 나가기 전)만 재시도한다 |
| 쓰기 요청 폭주 | 실행기 대기열은 500건까지 받는다. 넘치면 새 요청을 바로 거절하고 실패로 기록한다 |
| 워커 종료·응답 없음(2초 타임아웃) | 규칙은 계속 동작한다. "AI 중지"를 표시하고, launchd가 워커를 다시 띄운다 |
| AI 과부하 | 5.4의 정책을 따른다 |
| 맥 미니·네트워크 다운 | 모든 자동 기능이 멈춘다. 방송 전에 상태 점검 화면으로 확인한다 |
| DB | SQLite WAL 모드로 운영하고 매일 백업(7일 보관)한다 |
| 치지직 앱 삭제(90일 미사용) | 비시즌에도 최소한으로 사용한다 |

## 12. 외부 접속과 Cloudflare 전환 대비

- **지금**: Tailscale Funnel(`https://<기기>.<tailnet>.ts.net`)로 서버의 PWA, REST, WebSocket을 같은 출처에서 제공한다. 이 주소를 치지직 OAuth 리다이렉트 주소로 등록한다.
- **전환 비용을 낮추려고 지킬 것**
  1. PWA는 별도의 정적 빌드다. API 주소는 빌드할 때 설정값으로 넣는다.
  2. 쿠키나 토큰을 아는 코드는 서버의 세션 확인 부분과 웹의 API 호출 부분 **두 곳에만** 둔다.
  3. WebSocket은 티켓 방식이라 인증 방식이 바뀌어도 그대로 동작한다.
- **전환할 때 알아 둘 것**
  - Cloudflare Pages(정적 파일만): 화면과 API의 사이트가 달라진다. iOS Safari는 다른 사이트의 쿠키를 막으므로 인증 방식을 바꿔야 한다. Funnel은 ts.net 주소만 지원한다.
  - Cloudflare Tunnel: 엣지에서 TLS가 풀려 Cloudflare가 채팅 원문을 볼 수 있다. 처리위탁, 국외 이전, 약관 11호를 다시 검토한다.

## 17. 오픈소스 공개

- **라이선스**: Apache-2.0(`LICENSE`). 커밋 작성자 정보(이름·이메일)가 함께 공개된다. 사용자가 정한 사항이다.
- **저장소에 넣지 않는 것**: 치지직 Client ID·Secret, 토큰, `.env`, DB와 백업, 모델 가중치, 학습 데이터, 실채팅, 채널별 금칙어·허용어 목록, 파트너 채널 정보(채널명·규모).
- **기본 규칙 목록**: 저장소에는 최소한만 둔다. 목록이 공개되면 우회하기 쉬워지므로, 실제 운영 목록은 채널 DB에 둔다(11장 `rule_entry`).
- **모델**: 미세조정한 KcELECTRA는 배포하지 않는다. 학습 스크립트를 제공해서 각자 학습하게 한다. 직접 배포하게 되면 K-HATERS(CC-BY 4.0) 출처를 표기한다.
- **약관**
  - README와 화면에 비공식 프로젝트임을 밝힌다(제7조②14호).
  - 치지직 로고는 쓰지 않는다. 로고는 노란 번개와 방패로 만들었다(`assets/logo/`).
  - 운영자 책임(앱 각자 등록, 유료화 금지, API 사용 표시, 개인정보)을 README에 적는다.
- **확인 필요**: 약관 제7조②11호의 "API 등 정보 공개" 금지가 공개 코드에 미치는지 0단계 문의 메일에서 묻는다. 커뮤니티 라이브러리가 공개되어 있는 사례는 있지만, 대부분 비공식 엔드포인트를 쓴다.
